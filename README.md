# AIGC 来了，传媒生怎么办

《网络主播创作实践基础》课程汇报，10 页网页 PPT。

**在线看**：<https://meooochen.github.io/aigc-media-report/>

## 操作

- `←` / `→` 翻页，滚轮也行
- `P` 演讲者模式（需要允许浏览器弹窗，适合双屏）
- `ESC` 总览，点缩略图跳页
- `B` 关闭动态背景（旧电脑更流畅）
- 第 2 页的三张截图、第 6 页的留言截图，点一下可以放大，`ESC` 关闭

## 内容

同文案对照实验：真人出镜 vs AI 数字人。10 页里包含 21.7 万的上期复盘、三次试错的数据、评论区三种声音，以及"采 / 编 / 播"的拆解。

## 说明

- 页面是单文件 `index.html`，图片和视频在同级目录，纯静态，无后端。
- 字体优先用 Google Fonts 的思源宋体；访问不到时回落到系统宋体，排版不受影响。
- 数据来源：中国网络视听发展研究报告（2025 / 2026）、艾媒咨询《2026-2027 中国虚拟数字人产业发展与消费行为洞察报告》、小组抖音后台截图。
